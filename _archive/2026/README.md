# Archive: 2026 candidate recruiting

Saved October 25, 2026, after the October 24 listing deadline. Folders whose
names start with an underscore are not published by GitHub Pages, so these
files stay in the repository but do not appear on ward8votes.org.

- `declare.html`: the full candidate questionnaire page as it was live, with
  the embedded Google Form. To reuse it, copy it back to the top level of the
  repository (next to index.html) so its links to styles.css and nav.js work,
  then update the deadline, the form link, and the dates.
- `recruiting-sections.html`: the recruiting copy removed from index.html
  (the original hero, key dates, the "Run as a write-in" section, the empty
  state, the open-listing rules, and the main menu with the Run link).

Before reusing anything for a future election, re-check every date, deadline,
and Board of Elections link: they change every cycle.
